# 🏥 Smart Medical ID & Emergency Assistance System – Full Stack

A full-stack healthcare application developed as an advanced version of a previous QR-code-based medical identification project. The system helps individuals store and manage essential medical information and enables quick access to critical patient details during emergency situations through QR-code identification.

Unlike the original implementation, this version was developed using a modern service-oriented architecture, with Java Spring Boot powering the backend and Angular providing the frontend.

### ✨ Key Features

- 🏥 **Patient Management:** Create and manage personal medical profiles.
- 💊 **Medical Information Management:** Store important health conditions, medication details, and allergy information.
- 📱 **QR Code Integration:** Connect patient profiles with wearable QR-code identification bracelets.
- 🚨 **Emergency Information Access:** Retrieve essential patient information during emergency situations.
- 📞 **Emergency Contact Management:** Store and access registered emergency contacts.
- 🔐 **JWT Authentication:** Secure authentication and authorization using Bearer Tokens.
- 🔄 **RESTful API Architecture:** Backend services communicate with the Angular frontend through REST APIs.
- 📦 **DTO-Based Data Transfer:** Use Data Transfer Objects (DTOs) to structure and manage communication between application layers.
- 🧩 **Service-Oriented Backend:** Separate business logic into dedicated services for better maintainability and organization.
- 🗄️ **H2 Database Integration:** Use the H2 database for data storage and application development.

### 🏗️ System Architecture

**Backend – Java Spring Boot**
- REST API development
- Service layer architecture
- DTO-based data handling
- JWT authentication and Bearer Token authorization
- H2 relational database integration

**Frontend – Angular**
- Component-based application architecture
- API integration with the Spring Boot backend
- Dynamic user interface
- Authentication and protected application access

### 🎯 Project Goal

The main objective of this project was to redesign and modernize an existing medical identification system using a scalable full-stack architecture.

By combining Spring Boot backend services, an Angular frontend, secure token-based authentication, and structured data transfer, the project demonstrates the development of a modular healthcare application with a focus on maintainability, security, and efficient communication between frontend and backend services.
